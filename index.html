1. ダンジョン5種類

攻略が簡単な順に、ビギナー → ノービス → ホーリー → エキスパート → アンドロデンと覚えます。

★1 ビギナーダンジョン

一般的な敵が出てくる入門向けダンジョン。まずはここで「ダンジョン選択 → Lv選択 → 魔法の方針 → 挑む」という流れを覚えます。
系統効果：ドロップ率の分母が1減る

★2 ノービスダンジョン

ビギナーの次に挑戦するダンジョン。実画面では「ノービスダンジョン」「Lv3」の状態を確認できます。
系統効果：獲得ゴールドが15%上がる

★3 ホーリーダンジョン

一般的な敵が出現する上位側のダンジョン。周回や報酬確認にも注目します。
系統効果：経験値が2倍になる

★4 エキスパートダンジョン

竜などが出現する高難度ダンジョン。能力値・HP・魔法などを確認してから挑戦します。
系統効果：経験値が2倍になる

★5 アンドロデンダンジョン

正体不明のボスが出現する最上位ダンジョン。ボス戦を意識した準備が必要です。
系統効果：なし

種類敵攻略の位置づけ系統効果
ビギナー一般的な敵操作を覚えるドロップ率の分母が1減る
ノービス一般的な敵ステップアップ獲得ゴールドが15%上がる
ホーリー一般的な敵中級〜上級への入口経験値が2倍になる
エキスパート竜など高難度・強敵経験値が2倍になる
アンドロデン正体不明のボス最上位・ボス攻略なし

4. ドロップ・報酬を見る場所

通常報酬

戦闘ログに表示されるガウル・経験値などを確認します。

レアドロップ

アイテム名がログに現れたら、倉庫と合わせて確認。欲しいアイテムの周回記録を残します。

周回

ダンジョンLvと報酬をセットで記録すると、どこを回るべきか比較しやすくなります。

5. ワールド画面も実画面で解説

WORLD / MAP VIEW実画面ガイド
座標・移動・世界大戦・地図・土地詳細を一つの画面で確認できます。
① 現在座標現在地のX/Yを確認。
② 移動移動先のX/Yを入力して移動。
③ 世界大戦占領率と次回までの時間を確認。
④ 地図地形・拠点・周囲の領地を確認。
⑤ 土地詳細選択した土地の地形・距離・建設可否を確認。
⑥ 占領条件を確認して占領操作へ進む。

6. 要塞・領地の読み方

実画面の「毒沼」を例にすると

  • 地形：毒沼
  • 王宮まで：14マス
  • 建設：不可
  • 占領情報：自ギルドの占領地なので全ステータス +30%
  • 操作：「要塞を建てる」「占領する」
建設条件に注意：土地の詳細欄を確認してから操作します。実画面では、湖・聖域・王宮の周辺など建設できない条件も表示されています。
