1. ダンジョン5種類

攻略が簡単な順に、ビギナー → ノービス → ホーリー → エキスパート → アンドロデンと覚えます。

★1 ビギナーダンジョン

序盤向けのダンジョン。
系統効果：ドロップ率の分母が1減る

攻略：基本的な敵から戦闘に慣れる。

★2 ノービスダンジョン

ビギナーから一段階上のダンジョン。
系統効果：獲得ゴールドが15%上がる

攻略：敵の攻撃を見ながら各個撃破する。

★3 ホーリーダンジョン

経験値稼ぎにも向くダンジョン。
系統効果：獲得ガウルがたまに1増える

攻略：敵の属性や特殊攻撃に注意する。

★4 エキスパートダンジョン

高難度のダンジョン。
系統効果：経験値が2倍になる

攻略：強力な敵への対策を準備する。

★5 アンドロデンダンジョン

最上位クラスのダンジョン。
系統効果：なし

攻略：ボス戦を想定した装備と編成を準備する。

種類敵攻略の位置づけ系統効果

3. ダンジョン別・敵・ドロップ品カード図鑑

敵カードには、ダンジョンLV 1の戦闘開始時に実測したHPと、添付のダンジョンデータPDFに基づくドロップ情報を表示します。PDF内で実サイトの表記と差異があるものは、各カードで明記します。

HPは実サイトの戦闘開始時データ、ドロップ品・確率・効果は添付のダンジョンデータPDFに基づく情報です。実サイト表示名とPDF表記に差異があるものは未確定ではなく、対応関係を各カードに明示します。
統合表示：「ダンジョン別敵図鑑」と「敵・ドロップ品カード」を分離せず、各ダンジョンの中に敵カード、その中に全ドロップ品をまとめています。

敵カテゴリ出現ダンジョン難度確認できている特徴

竜などエキスパート★★★★強敵。上位装備・能力を整えて挑戦

4. ドロップ・報酬を見る場所

通常報酬

戦闘ログに表示されるガウル・経験値などを確認します。

レアドロップ

アイテム名がログに現れたら、倉庫と合わせて確認。欲しいアイテムの周回記録を残します。

周回

ダンジョンLvと報酬をセットで記録すると、どこを回るべきか比較しやすくなります。

5. ワールド画面も実画面で解説

WORLD / MAP VIEW実サイト・ダンジョンマップ
実サイトのダンジョンノード。入口から各系統を選択し、下部の選択欄でダンジョンとLVを指定します。
① 現在座標現在地のX/Yを確認。
② 移動移動先のX/Yを入力して移動。
③ 世界大戦占領率と次回までの時間を確認。
④ 地図地形・拠点・周囲の領地を確認。
⑤ 土地詳細選択した土地の地形・距離・建設可否を確認。
⑥ 占領条件を確認して占領操作へ進む。

6. 要塞・領地の読み方

実画面の「毒沼」を例にすると

  • 地形：毒沼
  • 王宮まで：14マス
  • 建設：不可
  • 占領情報：自ギルドの占領地なので全ステータス +30%
  • 操作：「要塞を建てる」「占領する」
建設条件に注意：土地の詳細欄を確認してから操作します。実画面では、湖・聖域・王宮の周辺など建設できない条件も表示されています。

8. チュートリアルサイトを改善する

開発者にプルリクエストを送る

「敵の情報を追加してほしい」「説明を修正したい」「UIを改善したい」など、サイトの改善案をGitHub経由で開発者に送れます。

接続先： ◆ GitHub

PRの流れ：GitHubで編集 → 自分のブランチへ変更を保存（Forkが必要な場合はGitHubが案内）→ Pull Requestを作成。
※GitHubへのログインや認証はGitHub公式画面で行います。このサイトにはGitHubのパスワードやアクセストークンを入力しません。

10. 開発者管理画面

管理対象：ダンジョン、敵、ドロップ品、攻略情報、更新履歴を一つの管理画面から編集できます。

🔐 開発者ログイン

この管理画面は、サイトの編集・更新履歴管理・GitHubへの反映をまとめて行うための画面です。

重要：静的HTMLだけでは本当の意味での安全なサーバー側ログインはできません。この版ではGitHubの認証情報をHTMLに埋め込まず、必要な操作時だけ開発者本人が入力する方式にしています。
更新履歴を一時追加しました。
